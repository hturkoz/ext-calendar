# for EspoCRM extensions: ext-calendar

**Calendar & Timeline**: Basic "print-to-pdf" functionality for personal calendar views (Week and Day layouts), including the timeline and navigation elements (DatePicker and arrows).

**Find Free Common Slots**: Opens a modal directly from the timeline to find shared availability. Select multiple users, set a date range (Start/End), choose a period preference (AM/PM), and EspoCRM will display the available open slots for a joint activity.

• Quick Edit Shortcut: A pencil edit icon appears in the bottom-right corner of events on mouse-up (Week and Day views) to quickly open the edit modal.
• Native Look & Feel: Fully respects the out-of-the-box EspoCRM color scheme and UI elements.
• Lightweight & Efficient: Kept lightweight and highly efficient for this specific use case.
